# PotPress project plan

PotPress is at stage P3 (TRL 3, design on paper), the portfolio's stage cap. The next gate is P4, a first prototype with a partner factory, which stays closed until Amish opens it. The decision requested now is D1 in PPR-DEC-001 (D6 waits for pressing trials). Method: STANDARDS sections 19 and 23.
